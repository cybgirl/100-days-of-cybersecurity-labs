## 🛠️ Installing Splunk Enterprise on Windows
1. Download **Splunk Enterprise** from the [official website](https://www.splunk.com/).  
2. Run the installer and follow the installation wizard.  
3. Choose the installation directory (default is fine).  
4. Set an administrator username & password for Splunk Web.  
5. Complete the installation and launch Splunk Web via `http://localhost:8000`.  
6. Log in and explore the platform.  

---

## 🛠️ Installing Splunk Universal Forwarder on Windows
1. Download **Splunk Universal Forwarder** from the [official website](https://www.splunk.com/).  
2. Run the installer and accept the license agreement.  
3. Choose the installation path and select **Forwarding & Receiving**.  
4. Specify the Splunk server’s IP & port (default: 9997).  
5. Set the Windows service account details if required.  
6. Finish installation and configure the forwarder to send logs to the Splunk instance.
