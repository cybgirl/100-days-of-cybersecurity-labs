# Day 1 – IT Fundamentals

## 🎯 Objective
To build a strong foundation in IT concepts essential for cybersecurity, including hardware, computing basics, and system components.

## 📚 Resource
- TCM Security – Practical Helpdesk Course

## 🧠 Key Topics Covered
- Introduction to IT and IT roles
- Basics of computing (binary, bits, bytes, encoding)
- Desktop components and hardware fundamentals
- BIOS and POST process
- Electrostatic Discharge (ESD) safety

## 🛠️ What I Learned
- Computers operate using binary (0s and 1s), which are translated into human-readable output.
- Understanding hardware components like CPU, RAM, and motherboard is essential for troubleshooting.
- BIOS and POST play a key role in system startup and diagnostics.
- ESD precautions are important when handling physical components.
