# Day 02 – System Fundamentals

## 🧠 Overview
Today’s lab focused on understanding core system fundamentals, including hardware, operating systems, and virtualization.

---

## 📚 Modules Covered

### 🔹 Module 5 – Laptop Components & Repair
- Learned about key internal components:
  - Battery, RAM, CPU, Drives
  - CMOS battery, motherboard differences
- Explored laptop vs desktop hardware differences
- Understood basic troubleshooting and replacement concepts

---

### 🔹 Module 6 – Operating Systems
- Deepened understanding of:
  - Abstraction & arbitration
  - API calls (Userland vs Kernel)
- Learned about:
  - File systems
  - Data storage in binary (1s and 0s)
  - File types (TXT, PDF)

---

### 🔹 Module 7 – Virtualization
- Learned about:
  - Virtual Machines (VMs)
  - Hypervisors (Type 1 & Type 2)
  - Containers vs Virtual Machines
- Installed and explored VirtualBox

---

## 🚀 Key Takeaways
- Strong system fundamentals are essential for cybersecurity
- Virtualization is critical for building safe lab environments
- Understanding OS internals helps in threat detection and analysis
