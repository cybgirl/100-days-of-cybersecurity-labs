# Day 03 – Windows Fundamentals

## 🧠 Overview
Today’s lab focused on Windows Fundamentals, a critical area for cybersecurity analysts. Understanding how Windows operates helps in system security, troubleshooting, and threat detection.

---

## 📚 Topics Covered

### 💻 Windows Architecture
- Explored user mode vs kernel mode
- Installed Windows 11 on a virtual machine
- Learned how Windows operates internally

---

### 🔍 Windows Registry
- Learned how Windows stores system and application data
- Understood its role in system configuration and performance

---

### 🛠 User Accounts & Permissions
- Explored:
  - Local vs Domain accounts
  - User roles and access control
- Learned about domain controllers and account management

---

### 📂 Processes & Services
- Used Task Manager to:
  - Monitor running processes
  - Analyze system performance
- Explored Device Manager for hardware management

---

### ⌨ Command Prompt
- Practiced essential commands:
  - `ipconfig`, `cd`, `cls`, `ping`
- Learned how to download executable files via CLI

---

### 📅 Task Scheduler
- Learned how to automate tasks and scripts
- Understood its importance in system management

---

### 🔒 Logs & Event Viewer
- Explored system and security logs
- Learned how Event Viewer helps in:
  - Monitoring activity
  - Detecting threats
  - Incident response

---

## 🚀 Key Takeaways
- Windows internals are essential for cybersecurity analysis
- Monitoring processes and logs is key for threat detection
- Command line skills improve efficiency and control
