# Day 04 – Linux Fundamentals

## 🧠 Overview
Linux is a cornerstone of cybersecurity, powering servers, networks, and many security tools. Today’s lab focused on understanding Linux fundamentals, including system structure, commands, and user management.

---

## 📚 Topics Covered

### 🐧 GNU/Linux & Distributions
- Learned about:
  - GNU/Linux (Linux kernel + GNU utilities)
  - Linux distributions (distros)
- Examples:
  - Kali Linux
  - Parrot Security OS
  - Ubuntu
  - BlackArch

---

### 💻 Installation of Ubuntu Linux
- Installed Ubuntu on a virtual machine
- Set up environment for hands-on labs
- Refreshed knowledge from previous Linux installations

---

### 📂 File System & Navigation
- Explored Linux file system hierarchy:
  - `/bin`, `/sbin`, `/lib`, `/etc`, `/home`, `/var`, `/tmp`
- Practiced commands:
  - `ls`, `cd`, `pwd`, `find`

---

### 🔐 User & Permissions Management
- Learned:
  - `chmod`, `chown`, `chgrp`, `sudo`
- Understood the importance of access control

---

### ⚙️ Process & Task Management
- Used commands:
  - `ps`, `top`, `htop`, `kill`
- Learned how to monitor and manage processes

---

### 🌐 Networking Basics
- Practiced commands:
  - `ifconfig`, `ip a`, `netstat`, `ping`
- Used for network troubleshooting

---

### 📦 Package Management
- Installed and updated software using:
  - `apt`, `yum`, `dnf`
- Learned the importance of keeping systems updated

---

## 🚀 Key Takeaways
- Linux is essential for cybersecurity operations
- Command-line proficiency is critical
- Understanding permissions helps secure systems
