# Day 05 – Network Fundamentals

## 🧠 Overview
Today’s lab focused on Network Fundamentals, the backbone of cybersecurity. Understanding how data moves across networks is essential for detecting threats and securing systems.

---

## 📚 Topics Covered

### 🌐 Introduction to Networking
- A network is a system of interconnected devices
- Key concepts:
  - LAN (Local Area Network)
  - WAN (Wide Area Network)
- Components:
  - IP address, routers, switches, hubs, DNS

---

### 🧱 OSI Model
- Learned the 7 layers:
  - Physical, Data Link, Network, Transport
  - Session, Presentation, Application
- Used for:
  - Troubleshooting
  - Threat detection
  - Securing communication

---

### 🔢 Network Addressing & Subnetting
- Types of addresses:
  - IPv4, IPv6, MAC
- Learned:
  - Subnet masks
  - CIDR notation
- Importance:
  - Network segmentation
  - Reducing attack surface

---

### 🔌 Common Ports & Protocols
- Ports enable communication between services
- Key protocols:
  - HTTP, HTTPS, DNS
  - TCP, UDP, ICMP

---

### 🔐 Virtual Private Networks (VPNs)
- Creates encrypted connections
- Practical:
  - Used OpenVPN client to connect to a remote server

---

### 🧪 Networking Labs
- Set up a SOHO router
- Performed network scanning using Nmap on Ubuntu
- Identified open ports on a server

---

### 🛠 Troubleshooting Commands (Windows)
- `ping`
- `ipconfig`
- `ipconfig /displaydns`
- `ipconfig /registerdns`
- `tracert`
- `netstat`

---

## 🚀 Key Takeaways
- Networking knowledge is critical for cybersecurity
- Subnetting improves security through segmentation
- Tools like Nmap help identify vulnerabilities
