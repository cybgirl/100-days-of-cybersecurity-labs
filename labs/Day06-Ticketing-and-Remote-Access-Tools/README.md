# Day 06 – Remote Support & Ticketing Systems

## 🧠 Overview
Today’s lab focused on Remote Support Tools and Ticketing Systems, both essential for cybersecurity analysts in troubleshooting, incident response, and system management.

---

## 📚 Topics Covered

### 💻 Remote Support Tools

#### 🔹 SSH (Secure Shell)
- Installed OpenSSH server on Ubuntu:
  - `sudo apt install openssh-server`
  - `sudo systemctl enable ssh`
  - `sudo systemctl start ssh`
- Connected from Kali Linux to Ubuntu using SSH
- Practiced key-based authentication using `ssh-keygen`

---

#### 🖥 Remote Desktop Protocol (RDP)
- Enabled Remote Desktop on Windows
- Used Remmina (Ubuntu) as the client
- Connected using Windows IP address

---

#### 🖧 VNC (Virtual Network Computing)
- Installed TightVNC Server on Windows
- Connected remotely using Remmina on Ubuntu

---

### 🎫 Ticketing Systems

#### 🔹 Peppermint (Open-Source Ticketing System)
- Installed Docker on Ubuntu
- Cloned Peppermint GitHub repository
- Deployed using Docker Compose

#### 🧪 Tasks Performed:
- Created users and clients
- Opened tickets
- Assigned and managed tickets
- Commented and closed tickets

---

## 📌 Importance in Cybersecurity

- 📊 Tracks and manages incidents efficiently
- ⚡ Enables prioritization and escalation of threats
- 📝 Maintains logs for compliance and audits

---

## 🚀 Key Takeaways
- Remote access tools enable fast incident response
- Ticketing systems improve workflow and organization
- Proper documentation enhances security operations
