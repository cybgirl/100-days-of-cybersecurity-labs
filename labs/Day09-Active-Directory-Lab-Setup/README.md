# Day 09 – Setting Up an Active Directory Lab

## 🧠 Overview
Today’s lab focused on setting up an Active Directory (AD) environment, a critical component of enterprise cybersecurity. Active Directory is widely used for identity and access management, making it essential for both defensive and offensive security operations.

---

## 💡 Why Active Directory Matters in Cybersecurity

- 🔐 Manages authentication and authorization
- 🏢 Used in most enterprise environments
- 🎯 Common target for cyberattacks
- 🛡️ Essential for both blue team (defense) and red team (attack simulation)

---

## 🛠 Lab Setup

### 🖥 Systems Used
- Windows Server 2025 – Domain Controller
- Windows 11 Virtual Machine – Client
- VMware – Virtualization platform

---

### ⚙️ Tools Used
- PowerShell – automation and configuration
- Sysinternals – system monitoring and analysis tools

---

## 📚 Lab Activities

### 1️⃣ Domain Controller Setup
- Installed Windows Server
- Promoted system to Domain Controller (DC)

---

### 2️⃣ Network Configuration
- Configured:
  - DNS (Domain Name System)
  - DHCP (Dynamic Host Configuration Protocol)

---

### 3️⃣ User & Group Management
- Created:
  - Users
  - Groups
- Applied access control policies

---

### 4️⃣ Domain Integration
- Joined Windows 11 client machine to the domain
- Verified domain communication

---

### 5️⃣ Authentication Testing
- Explored authentication protocols:
  - NTLM
  - Kerberos

---

## 🎯 Learning Objectives

- Understand identity and access management
- Simulate enterprise network environments
- Prepare for attack and defense scenarios

---

## 🔍 Security Insight
Active Directory is a primary target for attackers. Misconfigurations in user permissions, weak credentials, or poor policy enforcement can lead to privilege escalation and full domain compromise.

---

## 🚀 Key Takeaways
- Active Directory is essential for enterprise security
- Hands-on labs improve understanding of real-world environments
- Proper configuration is critical to prevent attacks
