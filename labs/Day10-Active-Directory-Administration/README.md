# Day 10 – Active Directory Administration & Real-World Challenges

## 🧠 Overview
Today’s lab focused on deeper Active Directory (AD) administration tasks, including domain management, organizational structuring, and policy enforcement. 

It was also a reminder that learning cybersecurity isn’t always easy—but consistency and resilience are key to growth.

---

## 📚 Topics Covered

### 🔗 Domain Integration
- Successfully joined a Windows 11 machine to the Active Directory domain
- Verified centralized authentication and policy application

---

### 🗂 Organizational Units (OUs) & Groups
- Created Organizational Units (OUs) to structure the directory
- Created groups to manage users and permissions efficiently
- Improved logical organization of users and systems

---

### ⚙️ Group Policy Objects (GPOs)
- Configured Group Policy Objects to:
  - Enforce security settings
  - Automate configurations
  - Manage permissions across domain systems

---

## 🎯 Learning Objectives
- Understand how enterprise environments manage users and devices
- Apply structured access control using OUs and groups
- Use GPOs to enforce security policies at scale

---

## 🔍 Security Insight
Misconfigured Group Policy Objects or poorly structured Active Directory environments can introduce serious security risks, including privilege escalation and unauthorized access. Proper configuration is essential for maintaining a secure domain.

---

## 🚀 Key Takeaways
- Active Directory administration is critical for enterprise cybersecurity
- GPOs are powerful tools for enforcing security policies
- Consistency and persistence are key when facing technical challenges

---

## 💡 Personal Reflection
Today highlighted an important truth: learning cybersecurity comes with challenges. Not every lab goes smoothly, and not every concept clicks immediately.

But progress comes from persistence. Showing up, troubleshooting, and continuing despite difficulties is what builds real skill.
