- Splunk helps with:
  - Log management
  - Security operations
  - Real-time monitoring
  - Threat detection and investigation

---

## ⚙️ Installation on Kali Linux
- Downloaded Splunk Enterprise package
- Installed using:
  - dpkg -i splunk_package.deb
- Started Splunk:
  - splunk start
- Accessed on browser:
  - http://localhost:8000
- Completed setup with admin credentials
