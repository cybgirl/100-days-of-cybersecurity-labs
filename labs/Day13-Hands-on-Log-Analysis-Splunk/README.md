# Day 13 – Hands-on Log Analysis with Splunk 🔍  

## 🧠 Overview
Today’s lab focused on hands-on log analysis using Splunk. I explored different types of logs, including DNS, SMTP, and HTTP logs, to understand network activity and identify potential security threats.

---

## 🎯Objectives
- Analyze DNS, SMTP, and HTTP logs using Splunk
- Identify suspicious patterns and anomalies
- Use Splunk dashboards for visualization
- Understand basic alerting for security monitoring

---

## 📚 Key Concepts Learned 
### 🌐 DNS Log Analysis
- Identifying suspicious domain queries
- Detecting possible DNS tunneling activity
- Monitoring unusual or repeated requests

---

### 📧 SMTP Log Analysis
- Tracking email traffic
- Detecting phishing attempts
- Identifying unauthorized email relay activity

---

### 🌍 HTTP Log Analysis
- Monitoring web requests
- Detecting unusual patterns in traffic
- Identifying possible SQL injection attempts
- Spotting unauthorized access attempts

---

### 📊 Splunk Dashboards & Alerts
- Visualizing log data using dashboards
- Identifying trends and anomalies
- Setting up alerts for suspicious activity

---

## 🚨 Importance
- Helps correlate logs from different sources
- Improves threat detection capabilities
- Supports real-time security monitoring

---

## 🚀 Key Takeaways
- Logs reveal important patterns and potential threats
- Splunk makes it easier to analyze and correlate logs
- Hands-on practice is essential for mastering log analysis
- Learning SPL is important for deeper analysis
