# Day 15 – Mastering the Fundamentals of Elastic Stack (ELK) 🔹  

## 🧠 Overview
Today’s lab focused on the Elastic Stack (ELK), a powerful solution for log management, monitoring, and security analytics. I explored how Elasticsearch, Logstash, and Kibana work together to process, analyze, and visualize data.

---

## 🎯Objectives
- Understand the components of the Elastic Stack
- Learn how ELK is used for log management and security analytics
- Compare ELK with Splunk
- Understand real-world SIEM use cases

---

## 📚 Key Concepts Learned  

### 🔍 Elasticsearch
- A distributed search and analytics engine
- Stores and indexes large volumes of data
- Enables fast search and retrieval of logs

---

### 🔄 Logstash
- A data processing pipeline
- Collects logs from different sources
- Transforms and sends data to Elasticsearch

---

### 📊 Kibana
- A data visualization tool
- Used to create dashboards and visualizations
- Helps in monitoring and analyzing security events

---

## ⚖️ ELK vs Splunk  

### 🔹 Similarities
- Log management and analysis
- Visualization and dashboards
- Fast search and indexing
- SIEM capabilities (threat detection, monitoring, incident response)
- Data ingestion from multiple sources

---

### 🔸 Differences
- ELK uses Logstash and Beats for data ingestion
- Splunk uses Universal Forwarders
- ELK uses Elasticsearch Query DSL for searches
- Splunk uses Search Processing Language (SPL)

---

## 🚨 Importance
- Helps in threat hunting and security monitoring
- Enables real-time log analysis
- Supports incident response and investigation
- Widely used in modern SOC environments

---

## 🚀 Key Takeaways
- ELK is flexible, open-source, and cost-effective
- Splunk is enterprise-ready with built-in support
- Both tools are important for cybersecurity professionals
- Understanding ELK improves log analysis and SIEM skills
