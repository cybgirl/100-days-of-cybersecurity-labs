# Day 18/100: Troubleshooting, Learning, and Expanding My SIEM Knowledge

Today was all about finding answers and pushing forward in my SIEM journey.

After struggling with my Elastic Stack configuration, I finally identified the issue: **insufficient system resources**.

💡 Running memory-intensive tools like **Elasticsearch, Kibana, and Logstash** on limited RAM isn't ideal. A simple **RAM upgrade** made all the difference—an important reminder when working with SIEM tools.

---

## What I Did

- Troubleshot Elastic Stack installation issues  
- Identified system resource limitations as the root cause  
- Upgraded RAM to improve performance  
- Explored additional SIEM tools:
  - AlienVault OSSIM  
  - Wazuh  
- Reviewed hardware and software requirements for SIEM deployment on a virtual machine  

---

## Key Takeaways

- ✅ Always check hardware requirements before installing SIEM tools  
- ✅ Elastic Stack, Wazuh, and AlienVault all have different resource demands  
- ✅ Learning one SIEM tool makes it easier to understand others  

---

## Reflection

This journey is full of **trial, error, and growth**, and each challenge is an opportunity to improve my troubleshooting and analytical skills.
