## 🎯 Objectives
- Understand the different levels of network security controls

---

## 📚 Key Concepts Learned

### 🔐 Security Control Levels
- **Physical Security**  
  Protects hardware, servers, and network infrastructure  

- **Technical Security**  
  Implements security technologies such as firewalls and encryption  

- **Administrative Security**  
  Defines policies, procedures, and guidelines for secure operations  

---

## 🔑 Network Security Approaches

### ✅ Access Control Measures
- **Firewalls** – Control incoming and outgoing traffic  
- **Network Access Control (NAC)** – Restrict unauthorized device access  
- **Identity and Access Management (IAM)** – Manage user identities and permissions  
- **Load Balancing** – Distribute traffic to improve performance and availability  
- **Network Segmentation** – Isolate network segments to reduce attack surface  
- **Virtual Private Networks (VPNs)** – Secure remote connections  
- **Zero Trust Model** – Enforces strict identity verification for every access request  

---

### 🚨 Threat Control Measures
- **Intrusion Detection & Prevention Systems (IDS/IPS)** – Detect and block malicious activity  
- **Data Loss Prevention (DLP)** – Prevent sensitive data exposure  
- **Endpoint Protection** – Secure devices connected to the network  
- **Cloud Security** – Protect cloud-based infrastructure and services  
- **SIEM & SOAR** – Monitor, analyze, and automate response to security events  
- **Network Traffic Analysis (NTA)** – Monitor traffic for anomalies

## 🚀 Key Takeaways
