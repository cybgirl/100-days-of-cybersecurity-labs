## 📚 Key Concepts Learned

### 🔍 What is Network Analysis?
Network analysis involves **monitoring, capturing, and examining network traffic** to identify:
- Security threats  
- Performance issues  
- Unauthorized access  

### 🛠️ Tools for Network Analysis
- **Wireshark** – Packet capture and analysis  
- **tcpdump** – Command-line packet analyzer  
- **Zeek** – Network monitoring and security analysis  

---

## 🖧 Network Devices and Their Roles

- **Router**  
  Directs traffic between different networks  

- **Switch**  
  Connects devices within a network for efficient communication  

- **Firewall**  
  Filters traffic to block malicious activity  

- **IDS/IPS**  
  Detects and prevents intrusion attempts  

Understanding how these devices interact helps identify vulnerabilities in a network.

---

## 🌐 Ports and Services

Every network communication occurs through **ports and services**:

- **Port 80 (HTTP)** – Web traffic  
- **Port 443 (HTTPS)** – Secure web traffic  
- **Port 22 (SSH)** – Secure remote login  
- **Port 53 (DNS)** – Domain name resolution  
- **Port 3389 (RDP)** – Remote Desktop access  

---

## 🔍 Security Insight
- Attackers often scan for **open ports** to find vulnerabilities  
- Unsecured services can be exploited for unauthorized access  
- Monitoring ports is essential for maintaining network security
