# Day 23 – Exploring tcpdump for Network Traffic Analysis 🖥️📡

## 🧠 Overview
Today’s lab focused on **tcpdump**, a powerful command-line tool used for capturing and analyzing network traffic. This session emphasized how tcpdump can be used for real-time packet inspection and network forensics.

---

## 🎯 Objectives
- Understand the basics of tcpdump  
- Capture live network traffic  
- Analyze `.pcap` files  
- Apply filters to isolate specific packets  
- Observe real-time network communication between systems  

---

## 📚 Key Concepts Learned

### 🛠️ What is tcpdump?
`tcpdump` is a lightweight, command-line packet analyzer used to:
- Capture network traffic in real time  
- Analyze packets based on protocols, ports, and IPs  
- Investigate network issues and security threats  

---

## 📡 Traffic Capture & Analysis
- Captured live network traffic using `tcpdump`  
- Analyzed a `.pcap` file to extract relevant information  
- Observed packet flow between systems  

---

## 🔍 Filtering Techniques
Used tcpdump filters to isolate and analyze specific traffic:

- Filter by IP address  
- Filter by protocol (ICMP, TCP, UDP)  
- Filter by port number  
- Combine filters for more precise analysis
