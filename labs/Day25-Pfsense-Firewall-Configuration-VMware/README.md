# Day 25 – Configuring pfSense Firewall on VMware Workstation 🔥

## 🧠 Overview
Today’s lab focused on **configuring pfSense as a firewall** on VMware Workstation. This hands-on session reinforced a key lesson: **a strong networking foundation is essential for SOC operations and cybersecurity professionals**.  

Firewalls are not just tools—they are the **first line of defense** in protecting networks. Understanding how to configure, monitor, and troubleshoot them is a critical skill for any cybersecurity analyst.

## 🎯 Objectives
- Install and configure pfSense on a virtual environment  
- Understand firewall rules and policies  
- Monitor traffic and log activities  
- Apply firewall configuration best practices  
- Strengthen practical networking knowledge for SOC operations  

---

- Deployed pfSense firewall on **VMware Workstation**

## 🔎 Security Insight
- Firewalls are **proactive security tools** that prevent unauthorized access  
- Effective configuration reduces the attack surface and strengthens enterprise defenses  
- Monitoring and logging network activity is as important as detection

## 🚀 Key Takeaways

- Hands-on practice with pfSense builds confidence in network security
