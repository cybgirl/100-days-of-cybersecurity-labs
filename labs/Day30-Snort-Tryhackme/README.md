## 📚 Key Concepts Learned

### 🔍 Introduction to Snort & IDS/IPS
- Snort is a **Network Intrusion Detection and Prevention System**  
- Helps detect and prevent malicious network activity  
- Plays a critical role in **SOC operations and threat monitoring**  

---

### 🛠️ Snort Operational Modes

- **Sniffer Mode**  
  Captures and displays live network traffic  

- **Packet Logger Mode**  
  Logs packets for later analysis  

- **PCAP Investigation**  
  Uses packet capture files for forensic analysis  

---

### 📜 Snort Rule Structure
- Rules define what traffic should be detected or blocked  
- Includes:
  - Rule header (action, protocol, IPs, ports)  
  - Rule options (content matching, metadata, flow)  
- Fine-tuning rules improves detection accuracy  

---

### ⚙️ Snort 2 Operation Logic
- Captures and inspects network traffic  
- Applies rules to analyze packets  
- Generates alerts when suspicious activity is detected
