# 📅 Day 37 – Network Forensics (DanaBot Challenge)

## 🧠 Overview  
Today’s lab focused on network forensics through the DanaBot challenge, a CTF scenario simulating a real-world security breach. The task involved analyzing network traffic to identify how a system was compromised and how sensitive data was exfiltrated.

---

## 🎯 Objectives  
- Investigate suspicious network activity using PCAP data  
- Identify indicators of compromise within network traffic  
- Analyze attacker behavior and data exfiltration techniques  
- Use threat intelligence to validate malicious files  
- Gain hands-on experience with network forensics tools  

---

## 📚 Key Concepts Learned  

### 🌐 Network Traffic Analysis  
- Analyzed captured packets to trace attacker activity  
- Identified communication patterns between compromised systems and external hosts  
- Detected signs of data exfiltration within network traffic  

---

### 🧪 File & Artifact Extraction  
- Extracted files and metadata from PCAP using NetworkMiner  
- Identified potentially malicious files for further investigation  

---

### 🔎 Threat Intelligence Analysis  
- Used VirusTotal to analyze file hashes and reputation  
- Leveraged community insights to validate suspicious artifacts  

---

## 🛠️ Tools Used  
- Wireshark – Packet inspection and traffic analysis  
- NetworkMiner – File and artifact extraction from PCAP  
- VirusTotal – Threat intelligence and hash analysis  

---

## 🚨 Identifying Security Insights  
- Compromised systems often communicate with external malicious servers  
- Network traffic can reveal hidden attacker activities  
- File extraction from PCAP is critical in forensic investigations  

---

## 🧠 Lessons Learned  
- Real-world scenarios improve analytical and investigation skills  
- NetworkMiner is effective for extracting files and evidence  
- Combining multiple tools provides better visibility during analysis  

---

## 🚀 Key Takeaways  
- Network forensics is essential for incident response  
- PCAP analysis can reveal the full story of an attack  
- Hands-on CTF challenges help bridge the gap between theory and real-world practice
