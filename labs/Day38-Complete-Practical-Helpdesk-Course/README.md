# 📅 Day 38 – Practical Help Desk Course (TCM Security)

## 🧠 Overview  
Today’s lab focused on completing the Practical Help Desk Course by TCM Security. This hands-on course simulated real-world IT support scenarios, providing practical experience in troubleshooting, system administration, and user support within an enterprise environment.

---

## 🎯 Objectives  
- Understand core help desk responsibilities and workflows  
- Gain hands-on experience with Active Directory (AD)  
- Learn how ticketing systems support incident management  
- Practice remote troubleshooting techniques  
- Develop command-line and PowerShell skills  
- Explore Windows system tools for issue diagnosis  

---

## 📚 Key Concepts Learned  

### 🖥️ Help Desk Fundamentals  
- Managed common user issues such as:  
  - Account lockouts  
  - Password resets  
  - Network and connectivity problems  
- Learned the importance of communication, patience, and structured troubleshooting  

---

### 🏢 Active Directory (AD)  
- Managed users, groups, and computers within a domain  
- Understood permissions and access control  
- Recognized AD as a critical component in enterprise security  

---

### 🎫 Ticketing Systems  
- Used a ticketing system to:  
  - Track and document incidents  
  - Manage issue resolution workflows  
  - Understand escalation processes and SLAs  

---

### 🌐 Remote Troubleshooting  
- Used tools such as:  
  - SSH – Remote command-line access  
  - RDP – Remote desktop management  
  - VNC – Remote system control  
- Diagnosed and resolved issues without physical access  

---

### ⚙️ Command Line & PowerShell  
- Executed commands for troubleshooting and system management  
- Learned basic scripting concepts for automation  

---

### 🪟 Windows System Analysis  
- Used Event Viewer to analyze system logs  
- Managed system services and configurations  
- Investigated system-level issues and errors  

---

## 🚨 Security Insights  
- Help desk teams are often the first to detect security incidents  
- User-reported issues can indicate phishing or compromise  
- Proper documentation improves incident response and tracking  

---

## 🧠 Lessons Learned  
- Strong IT fundamentals are essential for cybersecurity roles  
- Active Directory knowledge is critical for both defense and attack analysis  
- Troubleshooting skills directly support incident response  

---

## 🚀 Key Takeaways  
- Help desk experience builds a strong foundation for blue team roles  
- Understanding systems and users improves threat detection  
- Real-world simulations enhance practical cybersecurity readiness
